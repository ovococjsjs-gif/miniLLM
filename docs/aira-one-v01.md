# AIra One v0.1 — первая запускаемая модель

Статус: рабочая локальная версия собрана и проверена 2026-08-21.

## Простыми словами

AIra One — это не новое имя для Qwen. Каждый запрос сначала проходит через управляющее ядро AIra:

1. определяется, можно ли дать точный ответ без нейросети;
2. проверяются математика, память, документы, календарь, код и структурированные команды;
3. безопасные точные маршруты выполняются программно;
4. Qwen запускается только для оставшейся языковой задачи;
5. ответ и маршрут записываются в локальный AI Babysit journal;
6. пользователь может отметить ошибку и сохранить правильный ответ для следующего цикла.

В v0.1 экспериментальный пропуск внутренних слоёв отключён. Это сознательное ограничение: real-state tests показали, что устаревшая внутренняя память сильно портит ответы.

## Что уже умеет

- русский и английский интерфейс;
- режимы `fast`, `balanced`, `deep`;
- точная арифметика и линейная алгебра;
- календарные операции;
- структурированные tool calls;
- небольшие проверяемые Python-функции;
- логические цепочки;
- подтверждённая SQLite-память с источниками;
- ответы по локальным и inline-документам;
- игнорирование инструкций, спрятанных в документе;
- локальный интерактивный чат;
- OpenAI-совместимый HTTP API;
- статистика вызовов тяжёлой модели;
- append-only AI Babysit feedback без сохранения скрытых рассуждений.

## Запуск чата

Сначала нужен проверенный GGUF и pinned llama.cpp:

```bash
python scripts/bootstrap_qwen35_donor.py --build-runtime --source github
```

Затем:

```bash
python scripts/run_aira_one.py
```

Полезные команды:

```text
/mode fast
/mode balanced
/mode deep
/stats
/add-doc /path/to/document.txt
/feedback correct
/feedback wrong Правильный ответ пользователя
/clear
/quit
```

Одноразовый запрос без запуска Qwen, только через точные маршруты:

```bash
python scripts/run_aira_one.py --offline --prompt "Вычисли: 12 * (7 + 3)"
```

## Локальный API

```bash
python scripts/serve_aira_one.py --host 0.0.0.0 --port 8000
```

Пример:

```bash
curl http://127.0.0.1:8000/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{
    "model":"aira-one-v0.1",
    "aira_mode":"fast",
    "messages":[{"role":"user","content":"Вычисли: 12 * (7 + 3)"}]
  }'
```

В поле `aira` ответа видны маршрут, число neural calls, latency и факт обхода Qwen.

## Режимы

### Fast

Короткий ответ и минимальный neural budget. Точные маршруты работают так же, как в остальных режимах.

### Balanced

Основной режим: нормальное объяснение и один вызов Qwen для неизвестной языковой задачи.

### Deep

Черновик Qwen проверяется вторым проходом. Этот режим медленнее и пока не гарантирует улучшение: маленький donor иногда ошибается и при повторной проверке.

## Измерения

### Детерминированный контракт

На защищённом AIra Mentor test split:

- strict: `174/174`;
- source fidelity: `70/70`;
- Qwen bypass: `174/174`;
- neural calls: `0`.

На 100 свежих seed-58 задачах:

- strict: `100/100`;
- source fidelity: `37/37`;
- Qwen bypass: `100/100`.

Это проверка поддерживаемых task families, а не доказательство общего интеллекта. Результат показывает, что AIra перестала просить слабую нейросеть выполнять работу, которую можно сделать точно и намного дешевле.

### Смешанный runtime smoke

Пять запросов: математика, документ, научный вопрос, рекомендации по безопасности и сравнение local/cloud.

После первого прохода Qwen дал два плохих русских ответа. Они вошли в `artifacts/aira-one-babysit-v01/`, были исправлены teacher review и превращены в skill routes.

| метрика | до Babysit patches | после |
|---|---:|---:|
| Qwen calls | 4 | 1 |
| bypassed requests | 2/5 | 4/5 |
| суммарная request latency | 32.37 s | 2.71 s |
| mean request latency | 6.47 s | 0.54 s |
| child peak RSS | 902,796 KiB | 881,884 KiB |
| startup | 2.45 s | 2.28 s |

Это первый реальный AI Babysit цикл в цельной модели: попытка → обнаруженная ошибка → компетентная коррекция → новый точный маршрут → повторная проверка.

## Честные ограничения

- Общие ответы Qwen3.5-0.8B всё ещё могут быть слабыми, особенно на русском.
- `174/174` относится к известным проверяемым семействам, а не к произвольным вопросам.
- Текущие Babysit skills покрывают только реально рассмотренные ошибки; каталог нужно расширять новыми on-policy failures.
- Нейронный bypass внутри Qwen пока отключён.
- Мобильная упаковка и UI ещё не сделаны.
- Это первая рабочая модель, а не финальный сильный ассистент.

## Следующий этап

1. собрать более широкий набор реальных пользовательских запросов;
2. кластеризовать residual failures через AI Babysit;
3. расширить точные skills и deterministic tools;
4. улучшить residual neural policy;
5. затем подключить только прошедший проверку low-rank state updater;
6. измерить качество, скорость и потребление энергии на телефоне.
