# AIra One v0.1 package

The first integrated local AIra assistant. The Git package contains source, configuration, Babysit patches and measured evidence, including three broad cycles plus manual remediation over 24 topics; the verified 532.5 MB GGUF is restored separately by the pinned bootstrap process.

Run `python scripts/run_aira_one.py` for chat, `python scripts/serve_aira_one.py` for the local API, or `python scripts/run_aira_one_broad_babysit.py` to reproduce broad cycles.
