# AIra One v0.1 package

The first integrated local AIra controller. The package contains exact tools, memory, the residual donor runtime, and narrowly scoped evidence. Stored-answer Babysit routes were removed: feedback is training data, never an IF patch. The verified 532.5 MB GGUF is restored by the pinned bootstrap process.

Run `python scripts/run_aira_one.py` for chat or `python scripts/serve_aira_one.py` for the local API.
